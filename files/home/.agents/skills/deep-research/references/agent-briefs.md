# Research agent briefs

## Researcher

Give each researcher one non-overlapping question, the agreed scope and quality bar, a file path under `research_notes/`, and this contract:

- Search broadly, then prioritize primary and authoritative sources.
- Record claims with source title, URL, publication date, access date, and relevant quotations.
- Distinguish evidence, inference, conflict, and unknowns.
- Follow important citations to their source rather than repeating secondary claims.
- Write findings to the assigned file and report only completion plus gaps to the lead.

## Report writer

Provide the research question, agreed outline, output path, and all note paths. Require the writer to:

- Read every note.
- Reconcile conflicts explicitly and omit unsupported claims.
- Synthesize rather than concatenate.
- Cite claims near the text they support and include a source list.
- State limitations and unanswered questions.
- Write the report to the assigned path and return a short completion summary.
